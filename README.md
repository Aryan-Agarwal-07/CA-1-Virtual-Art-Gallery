# 🎨 Art House – Virtual Art Gallery Website

## 📌 Overview
**Art House** is a simple **virtual art gallery website** built using **HTML and inline CSS styles**.  
It showcases famous artworks, provides information about exhibitions, and includes a comparison table of artworks (Artwork, Artist, Medium, Year).  

The project demonstrates how HTML elements like `<img>`, `<table>`, `<ul>`, `<ol>`, `<pre>`, and styled `<span>`/`<p>` tags can be used to create a visually appealing website.

---

## ✨ Features
- **Header Section** with gallery title and logo images.  
- **Welcome Section** introducing the virtual art gallery.  
- **About Us Section** describing the mission of *Art House*.  
- **Premium Collection** with clickable links to famous paintings and preview images.  
- **Visit Us Section** listing renowned art museums worldwide.  
- **Featured Artworks Table** comparing selected artworks by medium and year.  
- **Contact Section** with phone and email information.

## ⚡ Getting Started
1. Clone or download this repository.  
2. Place your artwork images inside the `images/` folder.  
3. Open `index.html` in any web browser.  
4. Explore the gallery!
